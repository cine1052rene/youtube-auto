우리 콘텐츠는 어떤 콘텐츠인가

플랫폼 전략은 콘텐츠의 성격에서 출발해야 합니다. 곰곰한 마음이 어디서 강하고 어디서 불리한지부터 정리했습니다.

강점

  • 오리지널 캐릭터 — 니들펠트 곰곰이와 병아리 콩이. 배경 사진에 글귀만 얹는 수많은 '위로 채널'과 한눈에 구분됩니다
  • 이미 플랫폼 친화적인 구조 — 첫 컷 훅 질문 → 근거 있는 설명 → 작은 실천 → 마지막 질문. 마지막 질문은 그대로 댓글을 부르는 장치입니다
  • 출처가 있는 이야기 — 회복 경험 4요소, 부정성 편향, 에피쿠로스. 블로그 글과 X 타래로 넓힐 재료가 이미 있습니다
  • 사람이 다듬은 흔적 — 전 컷 프레임 점검, 내레이션 받아쓰기 검증, NG 아카이브. 'AI 대량생산'과 선을 긋는 증거입니다

조심할 점

  • AI로 만든 영상 — 유튜브는 문제없지만, 인스타그램은 2026년 '사람이 만든 콘텐츠 우선' 기조라 역풍이 붑니다
  • 편당 제작비가 큼 — 한 편에 45~65크레딧. 편수로 승부할 수 없으니 한 편을 오래, 여러 모양으로 써야 합니다
  • 34~45초 — 쇼츠·클립은 30초 안쪽이 완주율에 유리하다는 게 통설입니다
  • 위로·심리 주제 — 마음이 힘든 분이 댓글에 속마음을 털어놓을 수 있습니다. 대응 원칙이 먼저 있어야 합니다

한 목소리 가이드

다섯 플랫폼이 한 채널처럼 느껴지려면 말투가 같아야 합니다. 기준은 영상 자체에서 가져왔습니다.

  • 채널의 목소리는 영상의 해설자 — 따뜻한 존댓말, 짧은 문장. 내레이션 톤 그대로 씁니다
  • 곰곰이는 말하지 않는다 — 영상 속 곰곰이는 한 번도 말하지 않고, 콩이는 표정으로 반응합니다. 댓글과 게시물에서도 캐릭터는 괄호 속 지문으로만 등장합니다. 세계관을 깨지 않으면서 친근함을 더하는 장치입니다
  • 판단 대신 공감, 그리고 되묻기 — 해결책을 주기보다 이야기를 더 꺼내게 합니다
  • 조언·진단은 하지 않는다 — 우리는 상담사가 아닙니다. "그건 우울증 같아요" 같은 말은 절대 쓰지 않습니다
  • 출처 있는 말만 — 이론은 영상에서 다룬 근거 안에서만 이야기합니다
  • 이모지는 한 개까지, 반말과 과장된 감탄은 쓰지 않습니다

"곰곰이 너무 귀여워요"고마워요. (콩이가 곰곰이 머리 위에서 날개를 파닥여요)
"이런 건 다 뻔한 얘기 아닌가요"맞아요, 알고 있는 이야기일 수 있어요. 다만 알면서도 잘 안 되는 날을 위해 만들고 있어요. 어떤 부분이 아쉬웠는지 들려주시면 다음 편에 담아볼게요.

댓글 관리 — AI로 어디까지 되나

플랫폼마다 공식 도구와 규칙이 달라서, AI에게 맡길 수 있는 범위도 다릅니다.

플랫폼공식 도구AI 자동 답글우리가 쓸 방식
유튜브 Data API v3 무료. 하루 10,000단위, 답글 1건 50단위 → 하루 최대 약 200건. 스튜디오 자체에도 내 말투를 학습한 AI 답글 제안이 있음 가능 AI가 분류·초안 → 사람이 승인 후 게시
인스타그램 Graph API. 비즈니스·크리에이터 계정 + 댓글 관리 권한(앱 심사 또는 대행 서비스). 답글·숨김·삭제·좋아요 가능 스팸은 자동 숨김, 답글은 초안 승인
X API 종량제(답글 1건 0.010달러). 자동 답글은 나를 멘션·인용한 글에서만 허용 — 내 게시물에 달린 일반 답글은 해당 안 됨. AI 답글 봇은 X의 사전 서면 승인 필요. 웹 화면 자동화는 영구 정지 사유 초안만 AI가 초안 → 사람이 직접 게시
네이버 클립 공개된 댓글 API 없음. 클립 크리에이터 앱에서 관리 불가 앱에서 확인, 필요하면 AI에 붙여넣어 초안
네이버 블로그 공개된 댓글 API 없음 불가 주 1회 직접 확인

기존 X 자동화는 이 계정에 쓰지 마세요

C:\project\X_twitter의 답글 도구는 웹 화면을 스크립트로 조작하는 방식입니다. 2026년 X 규정상 이런 비(非)API 자동화는 영구 정지 사유라서, 곰곰한 마음 계정에 쓰면 브랜드 계정 자체를 잃을 수 있습니다.

운영 원칙: AI는 분류와 초안, 사람은 판단과 게시

기술적으로 완전 자동화가 되는 유튜브·인스타그램도 반자동으로 갑니다. 이유는 셋입니다. 위로 채널의 댓글은 사람의 속마음이 많고, 캐릭터 말투가 한 번만 어긋나도 세계관이 깨지며, 플랫폼들이 AI 대량 응답을 점점 더 경계하고 있기 때문입니다.

AI 분류예시처리
① 자기 이야기"저도 쉬는 날 폰만 봐요"공감 + 되묻기 초안 → 승인. 가장 많을 유형이고 가장 정성 들일 유형
② 질문"출처가 뭐예요?"근거 포함 초안 → 승인
③ 칭찬"곰곰이 귀여워요"좋아요는 자동, 답글은 몇 개만 골라서
④ 반박·비판"뻔한 얘기"사람이 직접. 방어하지 않고 인정할 건 인정
⑤ AI 제작 문의"이거 AI죠?"정해둔 답변(아래)으로 투명하게
⑥ 스팸·광고·혐오링크, 도배자동 숨김(유튜브 스튜디오 필터, 인스타 숨김 단어)
⑦ 위기 신호자해·자살 언급AI 답글 금지, 즉시 사람에게 → 아래 위기 대응

위기 대응 — 위로 채널이라면 반드시

  • 신호 — 자살·자해 언급, "사라지고 싶다", 극단적인 절망
  • AI 자동 답글은 절대 금지. 알림을 받는 즉시 사람이 봅니다
  • 짧게, 판단·조언 없이 — "여기까지 와서 말해줘서 고마워요. 혼자 견디지 않으셨으면 해요. 지금 많이 힘들다면 109에 전화해 주세요. 24시간 누군가 받아요."
  • 지우지 않습니다. 다만 방법 같은 위험한 정보가 담겼다면 숨김 처리합니다
  • 플랫폼의 신고 → 자해 위험 기능을 쓰면 해당 사용자에게 공식 지원 안내가 갑니다
  • 상시 안내 — 모든 플랫폼 소개글과 설명란 맨 아래에 한 줄을 넣어둡니다
