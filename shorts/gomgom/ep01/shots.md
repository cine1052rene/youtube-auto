# 1화 컷 구성 — 쉬어도 쉬어도 피곤한 이유

- 40초 = 영상 5컷(4초, V) + 그림 8장(2.5초, S)
- 영상 컷은 시작 그림(`vNN_start`)을 먼저 뽑고 그걸 움직임
- 모든 그림 프롬프트 = `[장면]` + 캐릭터 문장 + 그림체 문장 (series_bible.md 참고)
- 뽑을 그림: 영상 시작 5 + 그림 8 = 13장 (13크레딧) / 영상 20초 (20크레딧)

## 영상 컷 움직임 지시 (Veo, 소리 끔)
- 01: 곰곰이가 휴대폰을 느리게 넘기다 한숨 쉬듯 몸이 살짝 꺼짐, 카메라 거의 고정
- 04: 곰곰이가 하품하며 한 손으로 머리를 짚고, 콩이가 고개를 갸웃
- 10: 곰곰이가 휴대폰을 내려놓고 몸을 일으킴, 콩이가 날아와 어깨에 착지
- 12: 곰곰이가 컵을 들어 한 모금, 김이 피어오름, 아주 느린 밀기
- 13: 둘이 서로 쳐다보고 미소, 창밖 빛이 조금씩 따뜻해짐, 느린 뒤로 빠지기
