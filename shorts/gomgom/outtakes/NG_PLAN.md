# 시즌1 마무리 NG 영상 기획 (10/10 초안)

## 한 줄
"곰곰이 촬영장 사고 모음" — AI가 만든 실수를 숨기지 않고 귀엽게 보여주는 비하인드. 크레딧 0(전부 보관 중인 컷·소리).

## 형식
- 쇼츠 45~50초, 세로, 시즌1 편집 규칙(자막 1320 위치·제목 카드 3초·루프) 그대로
- 내레이션 없음 → 장면마다 짧은 자막 + 잔잔한 BGM, **소리 NG 구간만 원래 소리**를 살림
- 각 NG 3~4초: 사고 순간 직전부터 → 사고 순간 0.3초 정지 + "띠용" 대신 화면 살짝 흔들림(효과음 없음 규칙 유지)
