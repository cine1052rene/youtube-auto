# Daily Soul 당선작 자료실

매일 아침 hall-of-fame 확인 때 여기에 추가한다. 우리 생성 이미지는 힉스필드 Assets에 남으므로 PC에는 채점용으로만 받고 다음 날 지운다(프롬프트는 각 날짜 폴더 prompts.txt로 깃에 남음).

## 날짜별로 남길 것
- `YYYY-MM-DD.md`: 주제 원문(필수 조건) · 당선 5장(작가·점수 T/Q/O/E/P·한 줄 설명·링크) · 당선작 프롬프트(링크의 higgsfield.ai/s/ 페이지에서 복사) · 우리 최고작과 점수 차이 · 왜 졌나
- 카드 캡처는 jpg(가로 1000px 이하, 품질 80)로 줄여 저장

## 파일
