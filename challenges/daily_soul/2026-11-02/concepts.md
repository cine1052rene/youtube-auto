# 11/2 Useless Superpowers
주제(Higgsie 01:33): "He can turn invisible. Only when nobody is looking."
요구: **초능력이 진짜이고 멋져 보이는데 완전히 쓸모없는 영웅**. 에픽·드라마틱·시네마틱 — 능력은 작고, 포즈는 거창하게
예시(토스트 완성 아는 영웅·슬리퍼 신어야 빠른 스피드스터·비둘기 생각만 듣는 텔레파스·자기 소풍에만 비 부르는 여자·녹은 치즈에만 되는 레이저눈) 피함
이미 올라온 것: 기억 홀로그램 영웅(열쇠 못 찾음), 거대 공을 막는 히어로 옆 도둑
마감: 내일 새벽 1~3시. 1인 5장

## 어제 교훈
- 같은 소재도 **Quality(밝고 깨끗한 실사, 소품 결함 0)**가 순위를 가름 → 오늘은 히어로 영화 스틸급 조명·의상, 손·소품 결함 0
- 비틀기 문법: '진짜 멋진 능력 연출 × 사소한 결과' — 이펙트는 최대, 결과물은 최소

## 조건(검수)
① 히어로 의상·자세가 **영화급 거창** ② 능력 이펙트가 **진짜로 멋짐**(빛·에너지) ③ 결과가 **한눈에 쓸모없음** ④ 결함 0

## 컨셉 5개 (각 2장 = 10장, 1.2cr)
1. **번개 히어로 = 휴대폰 1% 충전** — 폭풍 옥상, 망토 휘날리며 하늘에서 번개를 손으로 끌어내리는 장엄한 포즈, 그 번개가 향하는 곳은 반대 손에 든 휴대폰 하나, 화면에 배터리 1%→2%
2. **염력 히어로 = 마지막 감자칩 하나** — 무너진 도시 한복판, 두 손 뻗어 보라색 에너지를 쏟아내며 공중에 띄운 건 감자칩 한 조각. 이마에 핏줄
3. **얼음 능력자 = 음료 하나 시원하게** — 사막 한가운데 서리 폭풍이 일어나는 장엄한 장면, 결과는 손에 든 레모네이드 컵 하나에 얼음 세 알
4. **시간 정지 = 떨어지는 아이스크림 받기 실패** — 온 세상이 멈춘 장면(공중에 멈춘 비둘기·물방울), 시간을 멈춘 히어로가 엄청난 포즈로 손을 뻗었는데 아이스크림 콘은 이미 바닥에 떨어져 있음
5. **불꽃 히어로 = 생일 초 하나** — 지옥불 같은 화염 기둥을 두른 히어로가 진지하게 손가락 하나를 내밀어 케이크 위 초 하나에 불을 붙임, 생일 아이는 시큰둥
