# 2026-09-28 Ocean's 88 — 컨셉 제안 (생성 전, 사용자 결정 대기)

주제: "One last job." 노인 범죄단이 벌이는 **말도 안 되는 강도 작전**을 보여줄 것.
예시(그대로 쓰면 Originality 감점): 보행기 도주 차량 / 빙고홀 금고 / 틀니 자물쇠 따기 / 레이저 그리드 속 낮잠 / 쿠키 단지 털기
채널에 이미 올라온 것(01:48 기준): 쇼핑카트에 돈다발 실은 할머니 / 밤 차량 도주

1. 보청기 금고털이 — 은행 금고 앞, 보청기 볼륨 최대로 다이얼 소리 듣는 할아버지, 뒤에서 뜨개질 바늘로 경보선 잇는 할머니
2. 크루즈 뷔페 새우탑 강탈 — 크루즈 뷔페 천장에서 털실로 로프 하강해 거대 새우 타워를 훔치는 실버 특공대
3. 품평회 거대 호박 절도 — 한밤 농산물 품평회, 전동 스쿠터 4대가 1등 거대 호박을 밧줄로 끌고 감
4. 시속 5km 추격전 — 전동 스쿠터 도주 vs 뒤에서 걸어서 쫓는 경찰, 오토바이 헬멧 쓴 할머니들
5. 카지노 금고 라인업(오션스 오마주) — 금고 문 앞 슬로모션 워킹, 정장+산소통·지팡이·링거대, 가방엔 금괴 대신 사탕
6. 브리핑 장면 — 요양원 휴게실, 칠판 대신 퍼즐판·빙고 칩으로 작전 설명, 설계도는 박물관 틀니 전시관
