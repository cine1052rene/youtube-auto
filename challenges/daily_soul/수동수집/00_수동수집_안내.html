3. 하루치 수집 순서 (예: 11/18 Snow Globe Life)

  1. 디스코드 앱 → 왼쪽에서 Higgsfield AI 서버 → #🏆|hall-of-fame 채널. 발표 글 제목은 "Daily Soul Challenge · Hall of Fame / Snow Globe Life · Nov 18" 형태 (다음 날 새벽에 올라옴).
  2. 발표 링크: 발표 글에 마우스를 올림 → 오른쪽 ⋯ → 메시지 링크 복사 → 링크.txt의 발표 뒤에 붙여넣기.
  3. 당선자 이름: 발표 글의 "Today's champions: @a @b @c @d @e" 순서대로 @ 칸에 아이디를 적는다.
  4. 공유 링크: 각 카드 아래 # daily-soul ›을 눌러 원글로 이동 → 원글 속 https://higgsfield.ai/s/… 링크에서 우클릭 → 링크 복사 → 그 사람 줄의 아이디 뒤에 한 칸 띄우고 붙여넣기.
  5. 카드 그림: 카드를 클릭해 크게 연 뒤 우클릭 → 이미지 저장(또는 다운로드) → 수동수집\2026-11-18\에 1.png, 2.png … 로 저장. 번호 = 링크.txt의 당선자 줄 순서.
  6. 메모장에서 Ctrl+S로 링크.txt 저장. 하루 끝.

4. 다 넣었으면 — 반영하기.bat 더블클릭

수동수집 폴더의 반영하기.bat을 더블클릭하면 ① 링크.txt·그림 읽기 → ② 공유 링크에서 프롬프트·모델 자동 수집(몇 분) → ③ 기록 페이지 갱신 후 자동으로 열림. 표의 "확인 필요" 칸이 ✅가 되면 그날은 완료.

하루씩 할 때마다 눌러도 되고, 여러 날을 모아 한 번에 눌러도 된다. 여러 번 눌러도 중복되지 않는다.
